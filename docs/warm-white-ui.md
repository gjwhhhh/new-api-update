# Warm White SaaS UI

视觉基准：`output/imagegen/warm-white-saas-recommended.png`。只借鉴 CASA 的暖白、留白和克制的可可棕强调；保留 New API 品牌、真实功能与权限。

## 固定配色

| --- | --- | --- |
| 页面背景 | `#F8F7F3` | `#201E1C` |
| 内容/卡片 | `#FFFFFF` | `#292623` |

默认圆角 12px；正文使用现有 Public Sans 与系统中文回退，数字使用 tabular-nums。色值集中于 `web/default/src/styles/theme-presets.css`，组件引用语义变量。无命名预设时生效，用户已选的其他预设、字体、圆角和密度设置不被重置。Body 层统一变量使弹窗、菜单和页面一致。

## 第一阶段实现

- 控制台顶部取消装饰性图片，统一边框与表面。
- 主内容区使用动态视口高度与可收缩宽度，保留既有内部滚动架构。
- 概览页主操作前置，接入引导默认收起，用户保存的展开偏好优先。
- 余额、近 24 小时消耗、累计消耗和累计请求数合并为一组响应式指标。不把累计指标误标为今日指标，不用虚构成功率。
- 7/30 天趋势使用个人日用量接口，聚合同一天的模型记录；缺失日期显示零，失败显示重试。
- 最近消费记录使用个人消费日志接口，即使当前用户是管理员也不扩大至全站数据。消费日志不等同于 HTTP 成功状态，因此不添加虚假的成功标签。
- 保留 API 路由配置、公告、FAQ、管理员性能与 Uptime 显示开关。
- 图表组件按需加载；新文案覆盖现有七个语言文件。

## 第二阶段：全站风格统一

- 首页、模型广场和排行榜沿用原有内容与交互，移除局部橙绿主题覆盖，继承共享配色；首页接入区域改为浅色中性表面，保留原有装饰素材并降低饱和度。
- 标题、按钮、卡片、表头、弹窗和抽屉采用共享变量；卡片使用真实边框，避免去除阴影时轮廓一并消失。
- 钱包指标在手机上纵向排列、桌面上三列分隔；个人资料金额与钱包统一数字字体。
- 密钥、日志、钱包、个人资料、渠道、订阅、系统设置、系统信息、模型详情、渠道状态、初始化和游乐场中的成功/复制/健康状态改用语义色；错误、警告仍保持独立语义。
- 登录布局允许内容超过视口时自然增长；设置和错误页移除多余背景装饰。
- 保留用户头像、供应商和支付品牌配色、代码语法色、权限、导航和既有功能。没有新增文案或翻译键。

## 边界与验证

首页例外（用户反馈后调整）：首屏背景图恢复原有彩色及不透明显示，移除灰度/棕褐滤镜，不再随后台风格去色。保留现有排版、响应式与交互；暗色仅降低图片亮度以保证文字可读。

首页按原会话代码恢复独立的石墨与朱红配色。首屏导航使用同色渐变托底：`rgb(252 251 249 / 0.86)` 至 `0.52`，在 58% 后渐隐到透明，不使用 `backdrop-filter`；滚动后显示 `rgb(252 251 249 / 0.74)` 与 24px 模糊的悬浮导航。主操作恢复朱红色和 2px 小圆角。此覆盖仅作用于首页，后台继续使用暖白与可可棕。

不修改后端、计费逻辑、classic 主题或部署。已检查代表性桌面页面、手机布局和设置页暗色；详见 `design-qa.md` 第二阶段记录。未提交付款、创建密钥或保存配置。普通账号、所有错误/加载状态和完整业务交互回归仍需专门测试，不以管理员页面检查代替；响应式视口验证不等同于实际浏览器缩放测试。
