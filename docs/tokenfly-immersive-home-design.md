# Tokenflyapi 沉浸式首页设计规范

## 设计目标

首屏是一个完整的沉浸式单屏场景：导航、品牌主张、主要入口、服务商示例与产品能力共同叠加在一张连续背景上，在一个视口内形成完整叙事。首屏之后继续承载模型生态、真实价格、快速接入、FAQ、转化入口和页脚，形成完整首页，而不是删除下半页内容。

## 视觉基准

- 审批稿：`output/imagegen/tokenfly-home-immersive-single-screen-v1.webp`
- 下半页视觉参考：`output/imagegen/tokenfly-home-below-cinematic-v1.webp`
- 无文字背景资产：`web/default/src/assets/tokenfly-immersive-hero.webp`
- 模型网络资产：`web/default/src/assets/tokenfly-model-network.jpg`
- 实现截图：`output/tokenfly-immersive-qa/implementation-desktop-final.png`
- 对照图：`output/tokenfly-immersive-qa/comparison-final.png`

背景资产由审批稿重新生成，移除了稿件中的品牌、文字、按钮和指标，页面上的所有产品文案和交互均使用真实 HTML，以保证可访问性、响应式与国际化。

## 视觉语言

- 字体：Inter Variable；中文使用系统无衬线回退。
- 主色：`#0d0d0d`。
- 次级文字：`#5d5d5a`。
- 场景底色：`#f4f4f3`。
- 强调方式：黑色胶囊按钮、银灰文字层级、细分隔线和少量半透明状态层。
- 图片语言：明亮单色建筑空间、白色陶瓷外壳、精密金属机械结构、低对比颗粒。
- 圆角：主要操作使用全圆角；小标签使用 8px 左右圆角。
- 阴影：只用于主要 CTA、品牌标记与兼容状态，保持低密度。

## 信息层级

1. 固定透明导航：保留项目真实导航、语言、主题、通知与账户入口。
2. 品牌主张：两行超大标题，第二行使用银灰层级。
3. 转化入口：开始接入为主操作，查看定价为辅助操作。
4. 服务商索引：OpenAI、Anthropic、Google、Meta、DeepSeek；入口统一连接真实模型广场。
5. 能力证明：40+ 渠道、One API/多协议兼容、可观测性/用量概览。
6. 模型生态：首屏完整结束后通过纯白留白进入独立章节；标题先于内容面板出现，面板使用抽象灰阶模型网络，并用三条真实能力完成叙事过渡。
7. 模型与价格：使用开放式横向列表呈现接口返回的真实模型和价格，不伪造模型卡片数据。
8. 快速接入：白底连续章节，左侧三步操作、右侧单一石墨色代码窗口；鼠标悬停、键盘聚焦和点击均可切换步骤。
9. FAQ 与收尾：两栏 FAQ 后接大面积黑色 CTA，最后恢复项目页脚及 attribution。

## 动效与交互

- 内容按 80ms 至 460ms 的节奏依次淡入。
- 桌面鼠标移动时，背景产生最大约 14px 的轻微视差，不触发 React 重新渲染。
- `prefers-reduced-motion` 下关闭视差过渡与抬升动效。
- 主 CTA、定价和服务商索引均使用真实路由。
- 下半页模型网络图片只做缓慢缩放；模型行、接入步骤和文本链接使用克制的位移/明暗反馈。
- 接入步骤保留悬停即切换，同时支持键盘聚焦与点击，避免只依赖鼠标。
- 键盘焦点保持 2px 高对比轮廓。

## 响应式规则

- 宽屏：左侧文案约占 54%，机器人保持右侧焦点；完整导航可见。
- 中屏：机器人向右调整裁切，避免压住标题；导航进入折叠菜单。
- 移动端：统一背景继续覆盖视口，增加浅色可读层；隐藏浮动兼容标签，服务商索引改为三列；底部能力证明保持三列紧凑布局。
- 页面不产生水平溢出；极矮或极窄设备允许最小高度保护内容，而不是裁掉主要操作。
- 模型生态与下半页在 820px 以下由双栏改为单栏；模型价格在窄屏隐藏但模型详情入口保留；代码窗口继续可横向滚动。

## 资产与实现约束

- 不使用新建 SVG 插画或 CSS 绘图替代主视觉；下半页也只使用真实位图资产与项目图标库。
- 首屏背景使用 1536 × 1024 WebP，压缩后约 60KB；模型网络使用 1448 × 1086 JPEG，压缩后约 215KB。
- 不在背景图中固化任何 UI 文案。
- 不伪造模型数量、可用性或延迟数据；能力证明只使用项目已有的可验证能力。
- 保留项目现有自定义首页 URL、HTML、Markdown 与公告弹窗分支。
- 首页视觉变化保持在现有组件和样式扩展点内，不引入新的前端依赖。
